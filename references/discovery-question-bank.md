# 需求澄清问题库

## 最少问题集（必问）

1. 这个版本的业务目标是什么？上线后用什么指标判断成功？
2. 目标用户是谁？他们当前主要痛点是什么？
3. 本次只做哪一条主链路？起点、终点分别是什么？
4. 主链路涉及哪些页面？每页完成什么任务？
5. 每个关键表单字段的校验规则是什么？
6. 成功、失败、加载中、空态分别怎么提示？
7. 需要适配哪些终端尺寸？
8. 当前最小可交付范围是什么？

## 按需追问（阻塞时再问）

1. 是否有需要模拟的角色权限差异？
2. 是否需要草稿、撤销、二次确认等保护机制？
3. 是否有关键异常场景必须演示？
4. 是否需要引导流程或新手教学层？
5. 是否存在必须保留的历史交互习惯？

## 确认摘要模板

请在开始编码前输出：

1. 主链路摘要（起点 -> 步骤 -> 终点）
2. 页面清单（页面名 + 目标任务）
3. 字段校验矩阵（字段 + 规则 + 报错文案）
4. 状态反馈矩阵（动作 + 加载中 + 成功 + 失败）
5. 本轮范围边界（做什么、不做什么）
